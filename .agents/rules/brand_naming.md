# Microbond Naming & Brand Integrity

1. **NEVER name any file, package, class, function, or variable with "whatsapp", "whatsap", or similar names.**
2. The project is **Microbond**. All components must use Microbond or domain-specific names (e.g., `GroupIntroCard`, `MicrobondDateDivider`, `MicrobondTheme`, `GroupDatePill`).
3. While the UI takes inspiration from modern messaging patterns, it is strictly Microbond and must never refer to third-party messaging apps in code, filenames, comments, or documentation.
